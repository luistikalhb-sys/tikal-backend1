# Tikal Backend

Backend API for Tikal Legend AI Ads OS.

## Endpoints

- `GET /health`
- `POST /api/chat`
- `POST /api/voice`
- `POST /api/businesses`

## Railway Start Command

```bash
npm start
```

## Required Railway Variables

```bash
OPENAI_API_KEY=
ELEVENLABS_API_KEY=
SUPABASE_URL=
SUPABASE_ANON_KEY=
META_ACCESS_TOKEN=
META_AD_ACCOUNT_ID=
```
